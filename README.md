# 🐳 CODSOFT DevOps Internship — Task 1

## Dockerized Web Application

A simple Node.js and Express web application containerized using Docker as part of my **CODSOFT DevOps Internship — Task 1**.

The application is built, packaged into a Docker image, run inside a Docker container, and published to Docker Hub.

---

## 🚀 Project Overview

This project demonstrates the basic workflow of containerizing a web application using Docker.

The application displays a responsive DevOps-themed webpage and runs on port `3000`.
